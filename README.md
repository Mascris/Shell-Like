# Shell-Like

A small shell implementation written in C, just for fun.

## About

I'm building this project to learn C through practice and better understand how command-line shells work on Linux.


## Goals

- Improve my C programming skills.
- Understand how shells parse and execute commands.
- Learn more about Linux and Unix-like systems.
- Get hands-on experience with systems programming.

## Built With

- C
- GCC
- Linux
- Git
- Makefile

## Build and Run

Compile the source code:

```bash
make
```

Run the program:

```bash
./shell
```

## Progress

This project is a work in progress. Features and improvements will be added as I learn and understand more about shell implementation.

## What I'm Learning

I'm using this project to connect C programming concepts with Linux.
